# 🔐 Java-Login-System

<p align="justify"> Created a login form using the Java programming language. This simple application helped me understand how Java works at a fundamental level and demonstrates a basic login interface with username and password validation. </p>

---

## 📌 Project Description

This is a desktop-based login system developed using:
- Java
- Swing (GUI)
- NetBeans IDE

The application allows users to:
- Enter a username
- Enter a password
- Show/Hide password
- Validate login credentials
- Exit the application

---

## 🖥️ User Interface Features

- Username field
- Password field
- Show Password checkbox
- Login button
- Exit button
- Validation error messages

## 🎮 How to Run the Project

1. Using NetBeans (Recommended)
2. Open NetBeans IDE
3. Click File → Open Project
4. Select the project folder
5. Run the project

---

## 🎯 Learning Purpose

This project was created to practice:
- Java GUI development
- Event handling
- Conditional statements
- Basic form validation
- JOptionPane usage
